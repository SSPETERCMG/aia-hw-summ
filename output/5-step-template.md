## ขั้น 3 · ประเมินมูลค่า (Valuation)

**คำถามหลัก:** ธุรกิจนี้มีมูลค่าเท่าไร ไม่ใช่ราคาหุ้นเท่าไร

| วิธี | สมมติฐาน (เขียนให้ชัดว่าเป็นของใคร) | มูลค่าต่อหุ้น | ที่มา/สูตร |
|---|---|---|---|
| P/E ย้อนหลังของหุ้นเอง (ต่ำ / กลาง / สูง) | | | |
| ผลตอบแทนปันผล vs ทางเลือกอื่น | | | |
| วิธีอื่น (DCF, เทียบคู่แข่ง) | | | |

**ก) P/E ย้อนหลัง 5 ปี (P/E band):** ราคาปิดสิ้นเดือน ÷ EPS ของปีนั้น (ปีล่าสุดที่ยังไม่จบใช้ EPS 12 เดือนล่าสุด)

| ปี | EPS | P/E เฉลี่ย | ต่ำ – สูง |
|---|---|---|---|
| ... | | | |

เฉลี่ย 5 ปี `[ ]` · SD `[ ]` · เฉลี่ยช่วงหลัง `[ ]` · ตอนนี้ `[ ]` · ตอนนี้ต่ำกว่ากี่ % ของเดือนทั้งหมด `[ ]`
เตือน: ถ้า EPS เปลี่ยนมากในช่วง 5 ปี (เช่น โต 2 เท่า) ค่าเฉลี่ย P/E จะเพี้ยน ห้ามใช้เป็นค่ากลางตรง ๆ ต้องอธิบายว่า P/E เปลี่ยนเพราะราคาหรือเพราะกำไร

**ข) P/E ข้างหน้า (Forward P/E)** = ราคาปัจจุบัน ÷ EPS ประมาณการ

| ปีประมาณการ | แย่สุด (Worst) | ฐาน (Base) | ดีสุด (Best) |
|---|---|---|---|
| EPS ปี N+1 (บอกอัตราโต) | | | |
| Forward P/E ปี N+1 | | | |
| EPS ปี N+2 / Forward P/E | | | |

อัตราโตของ EPS เป็นสมมติฐานของผู้กรอก ไม่ใช่ฉันทามติ ต้องเขียนเหตุผลว่าอิงอะไร

**ค) DCF 3 กรณี (FCFE = เงินสดที่เหลือถึงผู้ถือหุ้น):**

| รายการ (หน่วย) | ปีล่าสุด | ที่มา |
|---|---|---|
| เงินสดจากการดำเนินงาน | | |
| − ลงทุน (สินทรัพย์ถาวร ไม่มีตัวตน อสังหาลงทุน) | | |
| − จ่ายค่าเช่า | | |
| − จ่ายดอกเบี้ย (รวมดอกเบี้ยหุ้นกู้ด้อยสิทธิ) | | |
| − ปันผลที่บริษัทย่อยจ่ายให้ผู้ถือหุ้นส่วนน้อย | | |
| = FCFE (และต่อหุ้น) | | |

| กรณี | เงินสดโต 5 ปีแรก | โตต่อเนื่องหลังปีที่ 5 | อัตราคิดลด | มูลค่าต่อหุ้น | เทียบราคา |
|---|---|---|---|---|---|
| Worst | | | | | |
| Base | | | | | |
| Best | | | | | |

สูตร: FCFE ปีที่ t = FCFE ปีล่าสุด × (1+g)^t · มูลค่าปลายทาง = FCFE ปีที่ 5 × (1+g ต่อเนื่อง) ÷ (r − g ต่อเนื่อง) · มูลค่าต่อหุ้น = ผลรวมมูลค่าปัจจุบัน ÷ จำนวนหุ้น
คิดกลับด้าน (reverse DCF): ราคาปัจจุบันต้องการให้เงินสดโตปีละกี่ % `[ ]`
เตือน: อัตราคิดลดและอัตราโตเป็นสมมติฐาน ต้องเขียนว่าอิงอะไร · ถ้าเงินลงทุนรวมการขยายธุรกิจ FCFE จะต่ำกว่าที่ธุรกิจเดิมทำได้ ให้บอกข้อจำกัดนี้

ราคาตลาดปัจจุบัน `[ ]` เทียบมูลค่า: ต่ำกว่า / ใกล้เคียง / สูงกว่า · ถ้า P/E กับ DCF ให้ผลต่างกัน ให้เขียนว่าทำไม
**ข้อสงวน:** มูลค่าที่ได้เป็นช่วง ไม่ใช่ตัวเลขเดียว และขึ้นกับสมมติฐาน
**ตรวจกับดักมูลค่า (value trap):** ราคาตกเพราะอะไร ธุรกิจเสื่อมถาวรหรือแค่ชั่วคราว `[...]` · ราคาต่ำไม่ได้แปลว่าถูกหรือปลอดภัย · ตัวอย่างหุ้นตัวเดียวที่รอดมาไม่พิสูจน์อะไร ควรมีหุ้นที่ราคาตกแล้วไม่กลับมาไว้เทียบ `[...]`
**ไฟ:** 🟢 / 🟡 / 🔴 · `[...]`
