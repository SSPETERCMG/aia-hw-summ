## ขั้น 1 · วิเคราะห์จากล่างขึ้นบน (Bottom-Up)

**คำถามหลัก:** ธุรกิจนี้ทำเงินอย่างไร และดีพอไหมโดยไม่ต้องเดาเศรษฐกิจหรือจังหวะตลาด

| หัวข้อ | คำตอบ (ภาษาที่คนไม่เคยลงทุนอ่านเข้าใจ) | ที่มา · หน้า · วันที่ |
|---|---|---|
| บริษัทขายอะไรให้ใคร | | |
| เงินเข้าจากกี่ส่วนงาน และส่วนไหนทำกำไรมากสุด | | |
| ตัวขับเคลื่อนหลัก 2–3 ข้อ (เช่น จำนวนร้าน ยอดต่อร้าน) | | |
| ข้อได้เปรียบเหนือคู่แข่ง (ถ้ามี) เป็นข้อเท็จจริงหรือความเห็น | | |

## ขั้น 5 · บริหารความเสี่ยง (Risk Management)

**คำถามหลัก:** ถ้าผิด จะเสียเท่าไร และมีส่วนเผื่อความผิดพลาด (margin of safety) หรือไม่

| รายการ | คำตอบ | ที่มา/สูตร |
|---|---|---|
| ความเสี่ยงหลัก 2–3 ข้อ | | |

| สิ่งที่ต้องติดตามไตรมาสหน้า | | |
| สิ่งที่ยังไม่รู้ / ยังไม่ได้ตรวจ | | |
